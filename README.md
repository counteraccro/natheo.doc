Ce repository contient l'ensemble de la documentation de **Nathéo CMS**, hébergée via GitHub Pages. Il regroupe la documentation technique, fonctionnelle et les tutoriels sur tous les modules du CMS.

## 🛠️ Développement local

### Prérequis

- Node.js 18+ ou Python 3.8+ (selon le générateur utilisé)
- Git

### Lancer la documentation localement

> **Note** : Remplacez les commandes ci-dessous selon votre générateur de documentation (Jekyll, MkDocs, Docusaurus, etc.)
```bash
# Cloner le repository
git clone https://github.com/counteraccro/natheo.doc.git
cd natheo.doc

# Installer les dépendances (exemple pour Jekyll)
bundle install

# Lancer le serveur local
bundle exec jekyll serve

# Accéder à la documentation
# http://localhost:4000
```

## ✍️ Contribuer à la documentation

Les contributions pour améliorer la documentation sont les bienvenues ! 

### Comment contribuer ?

1. **Fork** ce repository
2. **Créez** une branche pour votre contribution
```bash
   git checkout -b docs/amelioration-section-x
```
3. **Modifiez** la documentation (respectez la structure existante)
4. **Commitez** vos changements
```bash
   git commit -m "docs: amélioration de la section X"
```
5. **Poussez** vers votre fork
```bash
   git push origin docs/amelioration-section-x
```
6. **Ouvrez** une Pull Request

### Guidelines de contribution

- ✅ Utilisez un français clair et professionnel
- ✅ Ajoutez des exemples de code quand c'est pertinent
- ✅ Incluez des captures d'écran pour les tutoriels UI
- ✅ Vérifiez l'orthographe et la grammaire
- ✅ Testez vos modifications en local avant de soumettre

### Structure des fichiers
```
natheo.doc/
├── docs/
│   ├── installation/
│   ├── guide-utilisateur/
│   ├── documentation-technique/
│   ├── design-system/
│   ├── modules/
│   └── tutoriels/
├── assets/
│   ├── images/
│   └── styles/
└── _config.yml
```
